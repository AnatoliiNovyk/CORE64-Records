### a) Як було до редагування
- Всі форми адмін-панелі приймали зображення/логотипи/обкладинки виключно через текстові URL-поля. Не було жодного завантаження файлів з комп'ютера.
- Весь інтерфейс був лише англійською мовою. Не було можливості перемикати мову.
- Дати відображалися без урахування локалізації.

### b) Які зміни було внесено та їх цінність

**Завантаження файлів (Requirement 1):**
- Створено публічний Supabase Storage bucket `media` з RLS-політиками для безпечного завантаження.
- Створено хук `useFileUpload` для завантаження файлів у Supabase Storage з генерацією унікальних імен.
- Створено UI-компонент `FileUpload` з підтримкою drag-and-drop, прев'ю зображень та стилізацією через дизайн-систему.
- У всіх адмін-формах (releases, producers, photos, events, partners, content) замінено текстові URL-поля на компонент завантаження файлів.
- Форма photos тепер вимагає файл замість URL.

**Інтернаціоналізація (Requirement 2):**
- Інтегровано `i18next` + `react-i18next` + `i18next-browser-languagedetector`.
- Створено повні переклади для англійської та української мов (200+ ключів).
- Всі hardcoded рядки у 20+ компонентах замінено на `t()` виклики.
- Додано компонент перемикання мови (LanguageSwitcher) у хедер лендінгу та панелі адміністратора.
- Локалізовано формат дат через `date-fns` locale (uk/enUS).
- Мова зберігається в localStorage та автоматично відновлюється.
- Атрибут `<html lang>` оновлюється динамічно.

### c) Як стало після редагування
- Адміністратори тепер завантажують зображення з комп'ютера напряму у Supabase Storage. URL-поля для зображень повністю видалено.
- Сайт повністю доступний українською та англійською мовами з миттєвим перемиканням.
- Збірка проходить без помилок TypeScript.
- Дати на сторінці подій та повідомлень відображаються відповідно до обраної мови.
