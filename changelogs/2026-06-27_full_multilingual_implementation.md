### a) Як було до редагування
- Приблизно половина тексту в адмін-панелі була захардкоджена англійською мовою і не перекладалась при перемиканні мов.
- Форми адмін-панелі не мали можливості вводити контент окремо для кожної мови (EN/UK).
- Публічна частина сайту не відображала локалізований контент з сутностей (releases, events, producers, videos, photos).
- Мова за замовчуванням була англійська, а не українська.

### b) Які зміни було внесено та їх цінність
- Змінено мову за замовчуванням (fallbackLng) на українську в i18n.ts.
- Додано десятки нових ключів перекладу в en/translation.json та uk/translation.json для всіх розділів адмін-панелі.
- Створено компонент LanguageTabs для перемикання мов у формах адмін-панелі.
- Додано колонку value_uk в таблицю site_content та JSONB-поле translations в таблиці releases, events, producers, videos, photos, partners (міграція бази даних).
- Оновлено всі сторінки адмін-панелі (content, releases, events, producers, videos, photos, partners, messages): замінено хардкоджені рядки на виклики t(), додано табки мов для полів що перекладаються.
- Оновлено хук useContentValue для вибору value_uk при українській мові.
- Створено утилітну функцію getLocalizedField для витягування перекладених полів з JSONB translations.
- Оновлено всі лендінг-компоненти (releases, events, producers, video, photo) для відображення локалізованого контенту через getLocalizedField.

### c) Як стало після редагування
- Українська мова є мовою за замовчуванням.
- Вся адмін-панель повністю перекладається при перемиканні мови (EN/UK).
- В адмін-панелі є табки для введення контенту окремо для кожної мови.
- Публічна частина сайту коректно відображає переклади з бази даних відповідно до обраної мови.
- Проект успішно компілюється без TypeScript помилок.
